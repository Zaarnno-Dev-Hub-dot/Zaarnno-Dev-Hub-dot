# Hi, I'm Zach 👋

I build **free educational browser games** and **local-first tools for working with AI agents**. Everything below is
open source (MIT), runs on your own machine or in a browser tab, and collects no data.

## Featured

### 🎮 [Learning Arcade](https://github.com/Zaarnno-Dev-Hub-dot/zaarno-learning-arcade) · [play it now](https://arcade-games-two.vercel.app)
Six browser games for kids: **Plumber Typing** (touch typing, row by row), **MathMan**
(a maze chase where math problems power you up), **Math Quest Runner** (a jungle platformer), **Math Blaster**, **Spelling Bee** and **GeoQuest**.

<a href="https://arcade-games-two.vercel.app"><img src="https://raw.githubusercontent.com/Zaarnno-Dev-Hub-dot/zaarno-learning-arcade/main/docs/screenshots/hub.png" alt="Learning Arcade" width="640"></a>

### 🤖 [AI Agent OS](https://github.com/Zaarnno-Dev-Hub-dot/ai-agent-os)
A local dashboard for running a team of AI agents in shared chat rooms. Every agent has to pass a proof-of-life
check before it is trusted. Works with ChatGPT, Claude, Grok, Cursor, Hermes and any OpenAI-compatible model.
